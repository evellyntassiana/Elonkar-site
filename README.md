# Site Centro Automotivo Elon Kar

Landing page da oficina Elon Kar (Areal - RJ) — https://elonkar.com.br

- `public/` — arquivos do site (index.html, robots.txt, sitemap.xml, _headers)
- Publicado no Cloudflare Workers (projeto `siteelonkar`), deploy automático a cada push na `main`.
- Edição de conteúdo: abrir o site com `?editar` no final do endereço.
